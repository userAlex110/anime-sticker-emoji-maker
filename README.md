# 动漫贴纸表情包 · Anime Sticker Emoji Maker

一个 Agent Skill：把用户发来的动漫角色参考图（贴纸实物照、电商截图、动画截图、官方立绘）还原成**原作画风**的透明底贴纸套图。

先做一张角色母版，再以母版为基准批量衍生表情（半身），或做全身变装；统一白色贴纸描边，自动去底，整版预览后交付。

## 两种任务模式

| 模式 | 触发说法 | 每人张数 | 景别 |
| --- | --- | --- | --- |
| 表情套组 | 做成贴纸 / 表情包 / 再来几张 / 每人 N 张 | 默认 4（招牌 + 3 变化） | 半身 |
| 变装套组 | 变装 / 换装 / 女仆装 / 洛丽塔 / 浴衣 / 圣诞 / 每人 N 套 | 用户指定，默认 3 套 | 全身 |

## 安装 / 使用

1. 把整个目录放进你所使用平台的技能目录（例如 `.skills/` 或 `.user_skills/` 下）。
2. 确保 `SKILL.md` 的 YAML frontmatter（`name` / `description`）能被平台读取。
3. 直接对 Agent 说：**「发一张角色图 + 做成贴纸，每人 4 张」**，或 **「每人来 3 套变装」**。

### 依赖

- Python 3 + `Pillow`（两个脚本都依赖）
- 一个支持「参考图 + 文字指令」的图像编辑接口（本版按 Seedream 5.5 调优）
- 去底能力：脚本调用 `mediakit-cli image remove-image-background --scene general`，可替换成任何抠图 API

```bash
pip install pillow
python3 scripts/check_alpha.py --dir ./成品
python3 scripts/make_sheet.py --src ./成品 --out ./00_整版预览.png --cols 4
```

## 为什么这套流程不容易翻车

1. **还原优先，不重设计**：参考图就是标准，禁止 Q 版三头身、禁止换成通用萌系脸。
2. **母版是唯一地基**：每个角色第一批只出 1 张母版，验收通过后才批量衍生。
3. **变装必须回到制服母版**：禁止拿上一套变装图继续派生，否则围裙、帽饰会一路传染。
4. **身份锚点串原样复述**：每个 request 复述同一串 5 要素锚点，只改最后一句「变化」。
5. **相近角色写排他句**：姐妹、同发色角色最容易互相污染，必须显式排除。
6. **透明化 + 整版预览 + 分组交付**：先发整版，再按角色分组发单张。

## 已验证跑通的记录

- 轻音少女 5 人 × 4 表情 = 20 张透明贴纸
- 3 人 × 3 套变装 = 9 张全身贴纸

## 适配到别的模型 / 平台

这套 Skill 的流程是模型无关的，但要换掉四处平台耦合：

| 原实现 | 需要替换成 |
| --- | --- |
| `image_edit` + `seedream_5.5` | 你的图像编辑接口与模型名 |
| `mediakit-cli ... remove-image-background` | 你的抠图服务 |
| `<RichMediaCard>` 交付 | 你的图片展示方式 |
| 1024×1024 生成、返回 1536×1536 | 目标模型的推荐尺寸，QC 里同步改 |

## 使用边界

- 只做校服、日常服、演出服、节日服、和服浴衣这类**非性化**服装。
- 不生成泳装、内衣、比基尼、露脐或深 V 等暴露款式；角色看起来是学生年龄时尤其要守住。
- 不用于原创角色设计、真人照片贴纸、商品图或海报设计。
