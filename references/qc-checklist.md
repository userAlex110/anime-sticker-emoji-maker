# 质检清单

## A. 母版（每个角色第 1 张）验收 —— 不过就只重出这一张，不要往下做衍生

- [ ] 画风是原作那种二维赛璐璐平涂、细干净描边，不是厚涂、不是三维渲染
- [ ] 是偏瘦长的少女头身比例，不是 Q 版三头身、不是大头娃娃
- [ ] 发型、发色、发饰数量与参考一致（发夹几枚、有没有发箍、马尾几条）
- [ ] 服装与领结颜色对（同一系列里不同年级领结颜色常常不同）
- [ ] 单人、正面、头部与上半身完整、居中、四周有留白
- [ ] 白色贴纸边闭合完整，外圈有极细灰描边
- [ ] 没有水印、价签、商家字样、logo、乱码
- [ ] 背景是透明，不是白底（或已知需要后续去底）

## B. 衍生张验收

- [ ] 和母版是同一个人：脸型、眼型、发际线、发饰位置一致
- [ ] 只有她一个人，没有别的角色、道具、纸张残留
- [ ] 白边没有断裂、没有压到脸上、没有突然变细
- [ ] 表情与动作符合预期，没有多长一只手、没有互斥动作
- [ ] 没有文字

## B·2 变装张专项（全身帖）

- [ ] 服装要素齐：围裙 / 蕾丝 / 缎带 / 帽子 / 披肩 / 鞋，少一件就是残件
- [ ] 没有混入别的服装（洛丽塔不该有白围裙，圣诞不该有校服领结，哥特不该是黑西装）
- [ ] 发型、发饰没变；发夹 / 发箍 / 双马尾仍然可见（帽饰不许把它们压没）
- [ ] 全身完整：头顶、手、鞋尖都在画面内，鞋有具体款式
- [ ] 不是露肩、无袖、露脐（除非用户明确要求且属于非性化款式）
- [ ] 配色属于这个角色（见 costume-library 的配色归属）

## C. 透明化流程

```bash
# 1) 先扫一遍，拿到需要去底的清单
python3 scripts/check_alpha.py --dir ./成品

# 2) 对 NO_ALPHA / OPAQUE 的逐个去底（general 场景才适合二次元）
mediakit-cli image remove-image-background --image-url "./成品/某某.png" --scene general
```

- 返回的 `image_url` 有效期 24 小时，**立刻下载回写**到成品目录，别只留链接。
- 去底后放到深色底上复核：白贴纸边是否完整保留、外圈有没有残留灰边/锯齿。
- 若抠图把白边吃掉（主体以外被当成背景切掉），优先改用生成时本来就带 alpha 的版本；没有的话重出一张，并在提示词里强化“白色贴纸白边+极细灰描边”。

## D. 常见缺陷对照表

| 现象 | 根因 | 修法 |
| --- | --- | --- |
| 返回的是白底 RGB | 生图偶发丢 alpha | `check_alpha.py` 扫出后走 mediakit 去底 |
| 抠图后白边没了 | 分割把描边外圈当背景 | 用原生透明版；或在 prompt 里强化白边；必要时自定义描边 |
| 角色变成双马尾 / 多了发夹 | 同系列相近角色污染 | 在锚点串里加排他句，单独重出这张 |
| 脸变宽、变 Q、变幼 | 缺比例约束 | 补“偏瘦长少女头身比例，禁止 Q 版三头身变形” |
| 参考图里的其他贴纸/水印入镜 | 参考是整版商品图 | 补“不要保留参考图中的其他人物、文字、水印、背景” |
| 手、吉他、鼓棒被画框裁断 | 没写构图 | 补“完整入镜”，或改成半身构图 |
| 出现乱码文字 | 模型自由加字 | 重出，并写“不出现任何文字、logo” |
| 一整套里有的全身有的半身，排版乱 | 动作混了景别 | 一套里全身动作最多 1 张，其余统一半身 |
| 洛丽塔被画成女仆 | 模型把蕾丝裙联想到围裙 | 加“没有白色围裙、没有荷叶边头饰”，单独重出 |
| 圣诞装变露肩晚礼服 | “无袖”联想 | 写死“长袖 / 毛边披肩，不要露肩” |
| 变装图里冒出校服领结 | 锚点串保留了校服段 | 变装时删掉校服/内搭/领结，只留发型与脸 |
| 帽子吃掉双马尾或发夹 | 头饰覆盖 | 写“双马尾从帽下露出”“发夹仍可见” |
| 变装缺鞋、光脚 | 没点名鞋子 | 写具体鞋款：玛丽珍鞋 / 短靴 / 木扉 |
| 三套变装越做越像 | 拿上一套变装图继续派生 | 每套都回到制服母版，不链式派生 |

## E. 交付前最后一遍

- [ ] 数量 = 角色数 × 每人张数，一张不多一张不少
- [ ] 命名统一：表情套组 `角色_序号_动作.png`；变装套组 `角色_变装_服装.png`
- [ ] 整版预览用的就是这批成品文件，不是旧版本
- [ ] 单张尺寸 1536×1536、透明 PNG
- [ ] 按角色分组发图：表情一套 4 张一组，变装一套 3 张一组
