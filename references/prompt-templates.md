# 提示词模板

## 一、母版提示词（每个角色第 1 张）

`image_edit` 实传该角色的干净参考图（图1），`width/height = 1024`，模型 `seedream_5.5`。
透明背景写在提示词里——`image_edit` 没有透明参数，只能靠这句话。

```text
参照图1中这位少女的长相与画风，重绘一张干净的单人半身贴纸立绘：{发型发色发饰}，{瞳色眼型}，身穿{服装}，内搭{内搭}，领口系{领结颜色}色细领结。保持原作二维日本动画赛璐璐平涂风格：平涂色块、极简阴影、细而干净的深色描边，禁止三维渲染与厚涂，禁止Q版三头身变形，保持偏瘦长的少女头身比例。表情：{第一个表情}。画面中只出现她一个人，正面朝向观众，完整露出头部与上半身；不要保留参考图中的其他人物、鼓、道具、文字、背景。人物外轮廓带一圈纯白贴纸白边，白边外再有一圈极细的灰色描边。透明背景生成，人物居中，四周留透明留白，不出现任何文字、水印或logo。
```

## 二、衍生提示词（第 2–4 张）

以母版为图1，同一批所有请求复述同一串身份锚点，只改最后一句。

```text
沿用图1中这位少女的长相、发型与画风，完全一致：{身份锚点串}；保持原作二维日本动画赛璐璐平涂风格、细干净描边、偏瘦长少女头身比例。透明背景，只有她一个人，白色贴纸白边+极细灰描边，四周留透明留白，不出现文字、水印、背景图案。变化：{表情与动作}。
```

## 二·B 变装模板（全身，用户要“换装 / 变装 / 女仆装 / 洛丽塔 / 浴衣 / 圣诞装”时用）

以**该角色制服母版**为图1。锚点串里**删掉校服和内搭、领结**，只保留发型发饰与瞳色眼型，否则校服会回流。

```text
沿用图1中这位少女的长相、发型与画风，完全一致：{发型发色发饰}、{瞳色眼型}；保持原作二维日本动画赛璐璐平涂风格、细干净描边、偏瘦长的少女头身比例，不要Q版变形。透明背景，只有她一个人，白色贴纸白边+极细灰描边，四周留透明留白，不出现文字、水印、背景图案。变化：她换上了{服装名}——{三到五个必写元素，含鞋子}；{服装排他句，例如“这不是女仆装，没有白色围裙、没有荷叶边头饰”}；{姿势与表情}，全身完整入镜（头顶到鞋尖都在画面内）。
```

服装必写元素与排他句见 [costume-library.md](costume-library.md)。

**变装不要链式派生**：第二套、第三套也回到制服母版，不要拿上一套变装图继续改，不然围裙、帽饰会一路传下去。

## 三、身份锚点串怎么写

从母版提示词里抽 5 个要素，按固定顺序拼成一句，每个衍生 prompt 原样复制：

```text
发型发色+发饰 / 瞳色+眼型 / 外套款式 / 内搭 / 领结颜色
```

实例（本次已验证可直接复用）：

- 平泽唯：`棕色及肩中长发与细碎外翘发尾、右侧刘海两枚黄色长条发夹、深棕色大眼与细眼线、深蓝色西装领水手服+白衬衫+浅蓝细领结`
- 秋山澪：`长直黑发与齐刘海、深棕色大眼与细眼线、深蓝色西装领水手服外套+白衬衫+浅蓝细领结`
- 田井中律：`茶棕色短发+亮黄色发箍将刘海篍起露出额头、琥珀色大眼、深蓝色西装领外套（敷开）+白衬衫+浅蓝细领结`
- 琴吹紬：`浅金色微卷长发、较粗浓的眉毛、蓝色大眼、深蓝色西装领水手服外套+白衬衫+浅蓝细领结`
- 平泽忧：`棕色短发在头侧后方扎小侧马尾并用黄色发圈系住（头上没有黄色长条发夹）、深棕色温柔大眼、深蓝色西装领外套+白衬衫+红色细领结`
- 中野梓：`黑色长发扎成两条高双马尾、齐刘海、深棕色大眼与细眼线、深蓝色西装领水手服外套+白衬衫+红色细领结`

## 四、排他句（外观相近的角色必写）

同系列里长得像的角色（姐妹、同发色）最容易互相污染，必须在锚点串里显式排除：

- 平泽忧 vs 平泽唯：`头上没有黄色长条发夹`、`只有一条小小侧马尾，另一侧头发自然散着，绝不要扎成两条双马尾`
- 中野梓 vs 澪：`两条高双马尾`（澪是长直发）
- 律 vs 紬：`亮黄色发箍露出额头`、`茶棕色短发`（紬是浅金长发）

## 五、固定负面指令

每张都带上，缺一条就会翻车：

```text
不要保留参考图中的其他人物 / 纸张 / 水印 / 商家字样 / 文字 / logo
只出现她一个人
保持偏瘦长的少女头身比例，禁止Q版三头身变形
禁止三维渲染与厚涂
```

参考图多为电商贴纸整版照片，一格里常有多角色、水印和价格字样，不写清楚就会一起画进来。

## 六、参数与批量

- 模型固定 `seedream_5.5`，尺寸 `1024×1024`（返回实际 1536×1536）。
- 单次调用 4–6 个 request；同角色 3 个衍生放一批，不同角色可拼一批。
- 每个 request 的 `image_reference_url_list` 只放**该角色自己的**参考图/母版，不要混别人的图。
- 请求之间不要串用生成结果；先拿到母版真实引用，再发衍生批次。
