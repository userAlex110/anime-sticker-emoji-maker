# 变装 / 换装配方库

用户要“剧中特色的变装”“每人来 3 套”时用这一份。

## 一、三套怎么选

一套变装的组合逻辑：**招牌一套 + 礼服一套 + 节日/季节一套**，同一个人三套之间不要同质（女仆 + 猫耳女仆 = 重复）。

- 系列里多人一起做时，用**配色归属**把人分开，避免九张图像同一批：
  - 平泽唯 → 草莓粉 / 红白
  - 秋山澪 → 黑 / 紫 / 浅蓝
  - 中野梓 → 黑 / 浅蓝 / 红
  - 田井中律 → 黄 / 橙
  - 琴吹紬 → 米金 / 浅蓝
  - 平泽忧 → 米白 / 棕 / 红
- 用户点名了具体服装就照做；没点名按上表挑，并在交付时说明选了什么、可以换。

## 二、服装配方表（必写元素 + 必须排除）

| 服装 | 必写元素（三到五个，写不全就会缺件） | 必须加的排除句 |
| --- | --- | --- |
| 女仆装 | 黑色长连衣裙、齐腰白色蕾丝围裙、白色荷叶边发饰、白色袖套 | `不是西装制服，不要领结` |
| 猫耳女仆 | 女仆装全套 + 黑色猫耳 + 猫爪手势 | `猫耳不要大过头发，双马尾要从猫耳下露出来` |
| 洛丽塔 | 泡泡袖、多层蕾丝蛋糕裙、缎带蝴蝶结、白色长袜、玛丽珍鞋 | `这不是女仆装，没有白色围裙、没有荷叶边头饰` |
| 哥特洛丽塔 | 黑紫蕾丝蓬裙、紫色缎带、蕾丝颈饰、黑色过膝袜、黑靴 | `不要画成黑色校服或西装` |
| 圣诞装 | 红色天鹅绒连衣裙、白色毛边、红色圣诞帽（帽尖白绒球）、长袖或毛边披肩 | `不要露肩、不要无袖` |
| 浴衣 | 浅蓝底白色小花、深蓝腰带、木屐、发簰 | `不是和服振袖，不要背后大腰带结` |
| 演出服 / 学园祭 | 与校服同色系的舞台装、领结、短裙 | `不要加乐器以外的道具` |

## 三、全身构图四要点（变装默认全身）

1. 写死 `全身完整入镜（头顶到鞋尖都在画面内）`，不写就会截到膝盖。
2. **鞋子必须点名**：玛丽珍鞋 / 短靴 / 木屐，否则脚部会被省略或画成光脚。
3. 手不要举过头顶或伸到画框外，裙摆两侧留白。
4. 同一套变装组统一全身，不要有的半身有的全身，整版才齐。

## 四、变装专属排他句（这次实际踩到的）

- 洛丽塔被画成女仆：`这不是女仆装，没有白色围裙、没有荷叶边头饰`
- 圣诞装被画成露肩晚礼服：`长袖/毛边披肩，不要露肩、不要无袖`
- 荷叶头饰压住刘海发夹：`发饰往后别，右侧刘海的两枚黄色发夹仍要看得见`
- 圣诞帽吃掉双马尾：`双马尾从帽子两侧露出来`
- 帽子/头饰把发箍遮没：`亮黄色发箍仍露在额前`

## 五、生成顺序（关键）

1. 以**该角色的制服母版**为参考（图1），只借脸、发型、发饰。
2. 变装提示词里的锚点串**删掉校服与领结**，只留 `发型发色发饰 + 瞳色眼型`；不删的话校服会回流到变装图里。
3. **所有变装都从制服母版派生，不要拿上一套变装图再派生下一套**——女仆的围裙会一路传到洛丽塔、圣诞上。
4. 每套单独一批，一次 3–6 个 request。

## 七、边界

- 只做日常服、校服、演出服、节日服、和服浴衣这类**非性化**服装。
- 不生成泳装、内衣、比基尼、露脐/深 V 之类暴露款式；角色看起来是学生年龄时尤其要守住。
- 用户明确点名要暴露款时不跟做，改成同主题的保守版本并说明。
