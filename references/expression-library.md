# 表情与动作库

## 一套 4 张怎么配

不要 4 张都换嘴。按“性格角色 → 情绪光谱”分配，每张至少变 2 项（眉眼、嘴型、头倾斜、手势、身体朝向、附加符号）：

1. **招牌**：最代表这个角色的常态（往往就是母版）
2. **元气**：外向的挥手/比耶/点赞/拍手
3. **爆发**：大哭、生气、震惊这类高对比情绪
4. **反差**：与性格相反的一张（害羞的人发火、元气的人发愣、嘴硬的人脸红）

## 按性格挑动作池

| 性格类型 | 推荐动作 |
| --- | --- |
| 元气外向 | 大笑挥手、双手比V、拇指点赞、举道具 |
| 害羞内向 | 低头微笑、慌张摆手、掩面、委屈含泪 |
| 温柔稳重 | 双手合十微笑、优雅招手、惊讶掩口、端茶递物 |
| 嘴硬后辈 | 抱胸扭头、鼓脸不服气、被夸掩面、抱着乐器 |
| 呆萌废柴 | 豆豆眼发呆、打哈欠、大字躺平、抱头大哭 |
| 认真严肃 | 抱臂皱眉、推眼镜式认真、训话手势 |

## 情绪符号词表（写进“变化”那一句）

用符号能明显拉开表情差，但别堆超过两种：

- 生气：`头顶冒出几道红色怒气线`、`一小团白色气团`
- 慌张/震惊：`额头旁挂着一滴蓝色汗珠`、`身后几道惊讶短线`
- 大哭：`两道宽宽的白色泪柱`、`周围飘着几颗蓝色泪珠`
- 委屈：`眼角挂着两滴将落未落的透明泪珠`、`嘴巴抿成向下的小小弧形`
- 兴奋：`双眼变成闪闪发光的星星眼`、`周围点缀几颗金色小闪光`
- 发呆：`双眼变成带小黑点的豆豆眼`、`圈圈眼`
- 困：`头顶漂浮逐渐变大的“Z”字母气泡`
- 害羞：`脸颊泛红`、`头顶冒出小小的白色热气`
- 得意：`闭眼露出小虎牙`、`下巴微微抬高`

## 道具与动作要点

- 乐器类道具（吉他、贝斯、鼓棒、键盘）要写清握持方向和“完整入镜”，否则会被裁掉半截。
- 手部动作最多两个，且不要同时安排互斥动作（例如双手捧脸又比V）。
- 全身动作（躺平、蹲着哭）会改变构图比例，一套里最多放 1 张，其余保持半身，整版才整齐。
- 校服是身份的一部分，不要为了“好看”换装；用户明确要求换装才换。
